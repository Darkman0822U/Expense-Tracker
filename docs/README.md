# Project Overview

## What this project is

Expense Tracker is a small web app for saving personal expenses.

## Why it was created

It was created to show a simple MERN stack project that is easy to understand and easy to run locally.

## What problem it solves

It helps a user keep a small list of expenses in one place.

## Who can use it

- Students
- Beginners learning MERN
- Anyone who wants to track daily spending

## Main features

- Add a new expense
- Edit an expense
- Delete an expense
- See all saved expenses
- See simple total spending information

## Technologies used

- React.js
- Node.js
- Express.js
- MongoDB
- Mongoose
- JavaScript
- HTML
- CSS

## How to install

1. Install the backend packages.
2. Install the frontend packages.
3. Add the MongoDB connection in `server/.env`.

## How to run

1. Start the server.
2. Start the React app.
3. Open the browser.

## Basic project structure

- `client/` holds the React app.
- `server/` holds the Express API and MongoDB model.
- `docs/` holds simple project documentation.
